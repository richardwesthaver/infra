* Overview
This project is used to build and maintain [[https://compiler.company][CC]] infrastructure.

As of [2025-01-20 Mon] this repository only works on our local
network. All build artifacts are retrieved from the subdomains of
compiler.company which were taken offline some time ago. I'll restore
them at some point but for now there is no great need as the services
are mirrored locally.

** Structure
The infra project contains a large collection of scripts used to build
install, update, and configure software for our machines.

There are four subprojects:
- home :: User home directories and configuration files
- etc :: System configuration files
- box :: VM and full system image scripts
- pod :: Containerfiles and build scripts
